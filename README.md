TITLE: WHACKALARM! The Alarm that fights you!
This robot is based off a central ESP 32 & LCD Screen that allows you to set alarms using a joystick controller.
These alarms are snoozed by the light switch on the back. The alarm function is connected to a 4 motor car that is set to move
erratically moving the alarm further from the person.
The alarm function is also connected to a servo motor used to bring an arm down to slap the unfortunate individual. Finally,
the alarm function is also connected to a buzzer to produce a blaring noise. 
This is all powered by a battery pack for the car and a USB power bank for the alarm itself. We had trouble with surging, so we had
to split power supply.
